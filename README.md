# Superstore Sales Dashboard (Power BI)
## 📊 Overview
This project presents an interactive Power BI dashboard analyzing sales, profit, customer segments, and regional performance.
## 🚀 Features
- KPI metrics: Sales, Profit, Orders, Margin
- Customer Segment Analysis
- Regional Performance Insights
- Profit Deep Dive
- Interactive filtering and drill-down
